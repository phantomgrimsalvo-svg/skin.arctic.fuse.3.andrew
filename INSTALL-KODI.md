# Install Andrew's Kodi addons (v1.2.0)

You need **Kodi 21 Omega**. Fire Stick / Shield / PC all work the same.

## INSTALL note (read this)

You can keep **jurialmunkey**, **ResolveURL**, and other **stock dependencies** installed. That is fine.

For these features you must use the Andrew forks only:

| Use this | Do not use for these features |
|---|---|
| **Cumination (Andrew)** (`plugin.video.cumination.andrew`) | stock Cumination (`plugin.video.cumination`) |
| **Arctic Fuse 3 (Andrew)** (`skin.arctic.fuse.3.andrew`) | stock Arctic Fuse 3 (`skin.arctic.fuse.3`) |
| **TMDb Helper (Andrew)** (`plugin.video.themoviedb.helper.andrew`) | stock TMDb Helper (`plugin.video.themoviedb.helper`) |

Stock Cumination / stock AF3 **will not** show portrait thumbs as the window background, and they **will not** frame site logos correctly.

Cumination is a **Video add-on**.

## After install

1. **Settings → Interface → Skin → Skin → Arctic Fuse 3 (Andrew)**.
2. Cumination (Andrew) settings: turn on **Use thumbnail as fanart** and **Also use portrait thumbs as fanart / background**.
3. Skin settings → **Colour**: Dual highlight colours, Colour A, Colour B.
4. Skin settings → **Fanart extras**: Extra fanart / Motion fanart, plus Letterbox / Zoom / Focus portraits.

Keep the jurialmunkey repo for `script.skinvariables` / `script.module.jurialmunkey`, and ResolveURL for Cumination playback.
